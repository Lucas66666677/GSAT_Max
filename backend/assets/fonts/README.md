# Bundled PDF Font

`NotoSansTC-Regular.ttf` is a static weight-400 instance generated from the
Noto Sans TC variable font published in the Google Fonts repository:

<https://github.com/google/fonts/tree/main/ofl/notosanstc>

- License: SIL Open Font License 1.1 (`OFL.txt`)
- SHA-256: `A2C0A7B385852F70B8C99073D2F769D058277B75921936B49E2C3EB37014D8FD`
- Purpose: embed Traditional Chinese glyphs in printable GSAT_Max PDFs so
  rendering does not depend on fonts or CMap files installed on the client.
